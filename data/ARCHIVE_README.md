# CPC/WSS historical validation evidence — distribution V3
29 October 2026. **Versioned research-evidence distribution; see the GitHub tag for public delivery.**

This collection supports the completed CPC/WSS technical investigation and the
SoftwareX draft. It contains original synthetic inputs, profiles/test registries,
oracle/source, stored decisions and exports, historical D3 SQLite views, and
source-bound historical join-engineering records. FILE_INDEX.csv/json describes
every selected original. Source bytes are exact copies; no result is regenerated.

Start with evidence/D1/DEPTH_D1_REPORT.md, evidence/D2/D2_REPORT.md,
evidence/D3/D3_REPORT.md and ORIGINAL_FREEZE_COVERAGE.json. Historical documents
can contain old commands and verdicts; these are evidence, not new authority.

Evidence classes and counts stay separate: D1 5,476 finite development cases;
D2 60 local mock cases; D3 64 archived references with zero verdict/export
differences. Historical D3 six-store outcomes were produced by
d3-opaque-sqlite-join-1.0.0 [0,100], not WSS join.analyze integer 0–4.
Engineering contains the 21-method source 1.11.0 receipt and the complete
receipt-bound sources; nine join dependency modules match source 1.12.0. No
fresh1.12.0 test, scientific experiment or native operation is asserted.

Four D2 cases D3-00014/00029/00044/00059 remain ADMIT / primary JOINED /
physical MISMATCH, with actual prompt AND generation differing from reported
approved values. The negative UF5 result stays NO_ADDED_LA_HANDOFF_VALUE.
Y_next stays NOT_MEASURED / NOT_VALIDATED_HERE; scripted 4/4/4 are not learning.

The data are deliberately synthetic. Test key strings are intentionally
insecure SYNTHETIC_ONLY fixtures, not production credentials. Current private
operator keys, SQL backups, cookies, raw HTTP captures and human learner data
are not selected. Old same-operator assertions and signatures do not provide
independent physical truth or institutional approval.

Original runner sources are included for traceability, NOT as a qualified
turnkey replay entry. Some original freeze manifests also bound internal
preflight/review files that are excluded from this distribution candidate.
Those manifests remain byte-exact; see ORIGINAL_FREEZE_COVERAGE.json and
OMISSIONS.json. Their original all-files guard may stop on omitted files.
Do not remove that guard or claim a full sealed replay from this subset.
The received inputs and result records remain inspectable without executing it.
The earlier full private collection and failures remain unchanged locally.

AI assistance to code/instrument preparation and author-directed inspection
must be disclosed; deterministic hashes/counts do not certify scientific
validity. UF5 is the recorded informed AI-assisted inspection/adjudication,
not independent human validation. This packet introduces no human study.
